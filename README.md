# Guru Pooja Book Sale Billing & Inventory System

A lightweight, local retail management application built with FastAPI and SQLite for the Guru Pooja celebrations.

## Setup Instructions

1. **Create a Virtual Environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application:**
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

4. **Access the System:**
   * Interactive API Documentation (Swagger UI): http://127.0.0
